PACPET COMPLETE WEBSITE
=======================

Pages included: Home, About, History, Vision & Mission, Founders, Educational Philosophy, Programmes, English Training, Phule Studies, Ambedkar Studies, Residential Programme, Faculty & Mentors, Alumni, Publications, Gallery, Events, Student Registration, Volunteer, Donate/Support, Contact, FAQs.

ADMIN
-----
1. Put the pacpet folder in C:\xampp\htdocs\
2. Start Apache and MySQL.
3. Open phpMyAdmin and import database/pacpet.sql.
4. Visit http://localhost/pacpet/setup-admin.php and create an admin account.
5. DELETE setup-admin.php after creating the admin.
6. Login: http://localhost/pacpet/admin/login.php

DATABASE
--------
config.php defaults to MySQL root with an empty password for XAMPP. Change it for your hosting provider.
